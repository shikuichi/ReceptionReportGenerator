# 受信報告書ジェネレーター (Reception Report Generator)

ラジオ（AM・FM・短波）やテレビ放送局向けの**受信報告書（ベリカード / 受信確認証 請求用）**を、ブラウザ上で直感的に作成・印刷できるスタンドアローン型Webツールです。

完全オフライン・スタンドアローン設計となっており、外部通信やサーバーへのデータ送信は一切行われません。プライバシーを保ったまま安全にご利用いただけます。

---

## 🌟 主な特徴

- **完全オフライン動作**: 外部CDNや外部APIへの通信を一切排除。フォルダ内の `index.html` を開くだけで動作します。
**ラジオ・テレビ双方の評価方式に対応**:
  - ラジオ: **SINPOコード**（強度・混信・雑音・伝播・総合）
  - テレビ: **P/Q評価**（映像 Picture / 音声 Quality）
- **リアルタイムA4プレビュー & 印刷最適化**:
  - 画面右側（PC時）に印刷時の用紙レイアウトを即時反映。
  - 入力文字数に応じたレイアウト自動調整（1枚収まり / 2枚以上向けスタイル）。
  - ブラウザの印刷機能（`Ctrl + P` / `Cmd + P`）でそのままA4印刷・PDF出力が可能。
- **日英バイリンガル対応**: 日本語フォーマットおよび海外局（BCL/DX）向けの英語フォーマットをワンクリックで切り替え可能。
- **データのバックアップ & 自動復元**:
  - 入力内容はブラウザ（`localStorage`）に自動保存。
  - JSON形式での全データ書き出し／読み込み、または「リスナー情報のみ（氏名・住所・連絡先・使用機材など）」のテンプレート保存に対応。
- **ランダムサンプルデータ生成**: 動作確認やレイアウト確認用に、架空の放送局・受信記録をワンクリックで自動入力できます。

---

## 🚀 使い方

1. 本リポジトリ（または配布ZIP）を展開します。
2. フォルダ内の `index.html` を任意のWebブラウザ（Google Chrome, Edge, Firefox, Safari等）で開きます。
3. 画面左側のフォームに受信日時、周波数、受信状態、番組内容等を入力します。
4. 入力完了後、ヘッダーの「**印刷 / PDF出力**」をクリックして印刷またはPDF保存を行ってください。

## 🛠️ カスタマイズについて

`app.js` 内の定数を編集することで、「リスナー情報のみ保存・読込」の対象項目の変更や、サンプルデータ機種の追加、長文レイアウト判定のしきい値などを自由にカスタマイズできます。

詳細な手順と全フィールドIDの一覧は **[カスタマイズガイド (docs/CUSTOMIZATION.md)](docs/CUSTOMIZATION.md)** をご参照ください。
